Markdown Cheat Sheet

  • # H1 → Heading 1
  • ## H2 → Heading 2
  • **bold** → Bold text
  • *italic* → Italic text
  • - List item → Unordered list
  • 1. List item → Ordered list
  • [Link](url) → Link
  • ![Alt](image_url) → Image
  • `code` → Inline code
  • ```code``` → Code block
  • --- → Horizontal line
  • GFM Tables: | Col1 | Col2 |
